# 🔐 Password Strength Checker

A simple web-based project built using HTML, CSS, and JavaScript that checks password strength based on rules like length, uppercase, lowercase, numbers, and special characters.

## ✨ Features

* Checks Weak, Medium, Strong passwords
* Real-time validation
* User-friendly interface
* Color-based strength indicator

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

* Open index.html in browser
* Enter password and click “Check Strength”

## 📌 Purpose

Helps users understand password security and improve password strength.
